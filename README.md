# FunPay csv

Консольная утилита на Rust для анализа истории продаж FunPay из CSV-файлов.

## Возможности

- Подсчёт выручки по каждой игре.
- Поддержка нескольких валют: RUB, USD, EUR и других.
- Учёт только успешно закрытых сделок со статусом `closed`.
- Сортировка игр по сумме продаж.
- Обработка больших CSV-файлов без загрузки всего файла в память.
- Запуск перетаскиванием CSV-файла на исполняемый файл.

## Использование

1. Скачайте исполняемый файл из раздела [Releases](https://github.com/Nevionn/Funpay-csv/releases).
2. Экспортируйте историю продаж FunPay в формате CSV.
3. Перетащите CSV-файл на `funpay_csv.exe`.
4. Результаты анализа появятся в консоли.

Программа группирует продажи по названию игры и валюте, выводит суммы по каждой игре и общий итог отдельно для каждой валюты.

## Сборка из исходного кода

Требуется установленный [Rust](https://www.rust-lang.org/tools/install).

```bash
cargo build --release
```
